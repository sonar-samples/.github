# Security

## Reporting a vulnerability

These repos contain sample code and workshop materials, not production software. The organization does not provide a public issue-reporting channel for sample-code vulnerabilities. Report a security issue in sample code through SonarSource's responsible disclosure process and identify the affected repository.

To report a vulnerability in a **SonarSource product** (SonarQube Server, SonarQube Cloud, SonarQube for IDE, SonarQube CLI), follow SonarSource's responsible disclosure process:

- **Email:** security@sonarsource.com
- **Full policy:** [Responsible Vulnerability Disclosure](https://community.sonarsource.com/t/responsible-vulnerability-disclosure/9317)
